# scene-previewer/ — 场景预览台（纯静态单 HTML）

> 双击 `scene.html` 即用；离线、零依赖（与本仓其他单文件工具同模式）。**版本 v0.1.0**

## 作用

素材「**游戏内比例实感**」的正式视检环境——避免放大看图的认知偏差：

- tilemap + sprite 摆位（底部 `SCENE` 数据即接入点）
- 分层帧动画（本体层 + 配件层**同钟合成**）播放
- 整数倍最近邻缩放、踩格线（tile 32px 整除画布）

## 接入

`scene.html` 底部 `SCENE` 常量为最小示例占位：

- `tilesets`：字符 → **32×32 单帧** sheet（多格 sheet 会取左上格并在状态栏提示）
- `map`：每字符一格；指向不存在的资产会在页面上显示加载失败

接入目标工程时替换为实际资产路径（部署路径口径见 `../knowledge/路径与部署映射.md`）。
