# 像素资产通用约定（pixel-* agent 共同基线）

> **效力**：本包全部 pixel-* agent 的共同约定。**具体项目基准**（像素密度与 tile 尺寸、各档位尺寸、朝向集、帧数指引、调色板文件、目录名）一律以**工作区 `AGENTS.md`** 为准；`AGENTS.md` 未定或缺失时向主代理索要，不得臆造。本文只定不随项目变化的硬规格。
> **基准唯一事实源**：改基准只改 `AGENTS.md` 一处；agent 定义、`layout.py` 前缀表、CI 门禁均以其为准，不同步改 agent 文件。

## 通用硬规格（不随项目变）

1. **原生分辨率**：导出原生尺寸 RGBA PNG，**禁止插值放大**；放大只允许 nearest 整数倍且仅用于检查图（渲染端 nearest 采样 + 整数缩放，禁平滑）
2. **透明度两态**：像素要么 alpha=0 要么 alpha=255，禁止中间 alpha（需求明确要求的半透明特效除外）
3. **色数与调色板**：单张 ≤16 色（含描边色，工作区约定可收紧）；颜色先入工程调色板（`assets/palettes/`）再使用，需要新色先入板
4. **描边与光源**：外轮廓 1px 深色描边且闭合；光源方向全项目统一（默认左上），明暗阶次一致（暗部 / 中间调 / 亮部 / 高光）
5. **命名**：全小写下划线。单图 `<类别>_<名称>[_<状态>].png`；序列帧 `<名称>_<两位帧号>.png`（从 00 起）；sprite sheet `<名称>_sheet.png`（横向，帧宽 = 原生宽）
6. **目录**：`assets/sprites/` 按资产名前缀分子目录（默认映射见 `tools/pixelart/layout.py`，前缀表按目标工程清单修订）；清单外基准资产落 `base/`；快稿 scratch 产物落 `previews/quick/<资产名>/`（不提交、用后即清）
7. **临时产物**：放大图、洋葱皮、网格检查图等自检产物只落**系统临时目录**，工作区不产生临时文件；`previews/` 只放交付给用户的预览
8. **受击闪白/发光等运行时效果**由渲染层染色实现，不烘进精灵、不加帧

## 工具门禁

- 程序化门禁唯一入口：`pixcli check ...` exit 0（用法与判读见 pixcli skill）
- 序列帧附加统计用 `pixcli anim`（纯信息，不设门禁）与 `pixcli onion`（洋葱皮检查图）
