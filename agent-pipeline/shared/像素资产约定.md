# 像素资产通用约定（pixel-* agent 共同基线）

> **效力**：本包全部 pixel-* agent 的共同约定。**具体项目基准**（像素密度与 tile 尺寸、各档位尺寸、朝向集、帧数指引、调色板文件、目录名）一律以**工作区 `AGENTS.md`** 为准；`AGENTS.md` 未定或缺失时向主代理索要，不得臆造。本文只定不随项目变化的硬规格。
> **基准唯一事实源**：改基准只改 `AGENTS.md` 一处；agent 定义、`layout.py` 前缀表、CI 门禁均以其为准，不同步改 agent 文件。

## 通用硬规格（不随项目变）

1. **原生分辨率**：导出原生尺寸 RGBA PNG，**禁止插值放大**；放大只允许 nearest 整数倍且仅用于检查图（渲染端 nearest 采样 + 整数缩放，禁平滑）
2. **透明度两态**：像素要么 alpha=0 要么 alpha=255，禁止中间 alpha（需求明确要求的半透明特效除外）
3. **色数与调色板**：单张 ≤16 色（含描边色，工作区约定可收紧）；颜色先入工程调色板（`assets/palettes/`）再使用，需要新色先入板
4. **描边与光源**：外轮廓 1px 深色描边且闭合；光源方向全项目统一（默认左上），明暗阶次一致（暗部 / 中间调 / 亮部 / 高光）
5. **命名**：全小写下划线。单图 `<类别>_<名称>[_<状态>].png`；序列帧 `<名称>_<两位帧号>.png`（从 00 起）；sprite sheet `<名称>_sheet.png`（横向，帧宽 = 原生宽）
6. **目录**：`assets/sprites/` 按资产名前缀分子目录（默认映射见 `tools/pixelart/layout.py`，前缀表按目标工程清单修订）；清单外基准资产落 `base/`；快稿 scratch 产物落 `previews/quick/<资产名>/`（不提交、用后即清）
7. **临时产物**：放大图、洋葱皮、网格检查图等自检产物只落**系统临时目录**，工作区不产生临时文件；`previews/` 只放交付给用户的预览
8. **受击闪白/发光等运行时效果**由渲染层染色实现，不烘进精灵、不加帧

## 资产来源路线（authored / sampled）

**同一份像素资产可以来自两条路线；派发与审查前必须先声明路线，硬规格按路线分流适用。** 路线是**风格选择**，不是质量等级——authored 追求逐像素可控，sampled 追求快速覆盖。

| 路线 | 来源 | 典型产出者 | 定位 |
|---|---|---|---|
| **authored**（手绘 / 重绘，默认） | 人画，或按参考重绘 | pixel-artist / pixel-imitator / pixel-quick | 逐像素可控，**全部硬规格强制** |
| **sampled**（采样像素风格） | 任意图片 / 视频经工具采样 + 量化生成 | `pixel-toolkit`（`standardize` / `video-std`）、`asset-inspector` 处理链路 | 快速风格化，逐像素可控性弱，**部分硬规格放宽**（见下表） |

**sampled 路线的规格适用**（未列出的照 authored 执行）：

| 硬规格 | authored | sampled |
|---|---|---|
| 原生分辨率、禁插值放大 | 强制 | 强制（采样输出即原生；放大仅 nearest 且仅检查图） |
| 透明度两态 | 强制 | 强制（工具侧「alpha 两态化」） |
| ≤16 色、颜色先入板 | 强制 | **按归板后计**：先归入工程调色板（`asset-inspector` 归板 / `pixcli quantize --palette`）再数色；归板后仍超 16 色的资产不适合 sampled 路线 |
| 描边闭合、明暗阶次、光源方向 | 强制 | **不强制**：描边由工具统一生成，明暗阶次不保证 |
| 帧尺寸一致 | 强制 | 强制 |
| 帧组锚点 / 脚底对齐 | 强制 | **不强制**：源素材自身运动导致 bbox 漂移属路线固有；只要求帧尺寸一致 |
| 循环动画帧间一致性 | 强制（死帧/跳变/循环突断） | 按 `pixcli stability` 读数判读（阈值 `--max-flip` / `--max-colors` 由项目定），不按手绘标准强判 |
| 命名 / 目录 | 强制 | 强制 |

**路线声明**：派发规格写明 `路线：authored | sampled`；交付 JSON 用 `meta.sourceRoute` 记录（**工具链已产出**：`video-std`/`video-studio` 写 sampled、`asset-inspector` 可选，`pixcli atlas` 校验；未标注时按 authored 处理）。**sampled 资产能否进工程是项目级决定**（哪些资产类别允许采样风格，写在工作区 `AGENTS.md`）；主角、需要精确动作曲线或强剪影一致性的资产默认仍走 authored。

## 工具门禁

- 程序化门禁唯一入口：`pixcli check ...` exit 0（用法与判读见 pixcli skill）
- 序列帧附加统计用 `pixcli anim`（纯信息，不设门禁）与 `pixcli onion`（洋葱皮检查图）
