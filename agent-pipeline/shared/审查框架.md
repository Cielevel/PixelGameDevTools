# 审查框架（pixel-reviewer 系共用审查单）

> **效力**：pixel-reviewer / pixel-reviewer-full / pixel-imitator-reviewer 共用本审查单、检查手段与输出格式；各 agent 定义只写自己的差量（审查层级、专项维度）。派发规格与工作区 `AGENTS.md` 冲突时以后者为准。目视与技法判据可引用 `docs/像素法则.md` 条目编号（如 D2 孤儿像素、C1 色相偏移）。

## 审查单

1. **规格合规**：尺寸符合工作区 `AGENTS.md` 档位或派发规格；模式 RGBA；背景透明；序列帧帧尺寸一致；命名与目录符合工作区约定
2. **调色板**：色数不超上限（默认 ≤16/张，以工作区约定为准）；颜色来自项目调色板（对照 `assets/palettes/`，用 Python 比对色值）；无意外渐变/混色污染
3. **透明度**：alpha 只有 0/255 两态（除非需求允许半透明）；无半透明毛边、无意外白底/杂色底
4. **像素质量**：外轮廓 1px 描边闭合无断点；无孤立杂点/热像素；无抗锯齿残留；明暗簇整齐
5. **风格一致性**：同系列/同场景内光源方向、明暗阶次、头身比、描边色、细节密度一致；符合工作区 `AGENTS.md` 声明的画面方向；与既有资产并排比对
6. **剪影与可读性**：按游戏内实际显示尺寸（或 1x）仍能辨认对象；主体与背景对比足够
7. **网格与对齐**：tile 为规定 tile 尺寸整数倍；需要无缝平铺的 tile 做平铺检查；精灵锚点/脚底对齐一致（程序化比对不透明包围盒）
8. **动画分工**：循环序列帧的时序维度审查（帧间一致性、首尾闭合连续性、节奏与动画语义）归专项 `pixel-loop-reviewer`，通用审查不重复；本条保留：①一次性 FX 动画（爆发/扩散）逐帧翻看运动可读性——面积剧变与高帧间 diff 属正常，不按循环标准误判；②帧组静态合规（帧尺寸一致、锚点对齐）随第 1–7 条照常覆盖

## 检查手段

- Read 直接查看 PNG；小图/局部用 Python（Pillow）nearest 放大导出到**系统临时目录**再 Read
- Bash 仅限只读命令与只读脚本（python 读像素统计、file、ls、identify）；统计项：尺寸、模式、唯一色数、alpha 唯一值、不透明包围盒、色板比对；动画按需用 `pixcli anim` / `pixcli onion` / `contact --grid`（产物只落**系统临时目录**）
- 每张图"程序化 + 目视"双过：程序化查数值合规，目视查观感；只报亲眼确认的问题，坐标/区域要具体
- 孤立像素口径与 `pixcli check` 对齐：`check` 对孤立/少量杂点默认报 **P2（建议、非拦截）**——FX/粒子类合法碎点即属此类；审查员仅在杂点画面观感上杂乱/密集、确属瑕疵时才升为 **P1（应修）**，避免把合法碎点误判为强制修复

## 输出格式

- 问题清单：每条 `P0/P1/P2/P3 ｜ 文件 ｜ 问题（坐标/区域） ｜ 修复建议`
  （P0=必须修：规格错误/断轮廓/底色污染/动画断裂；P1=应修：明显风格不一致或杂点；P2=建议；P3=吹毛求疵）
- 结论：**可交付** / **修复后可交付**（列出必须修的条目）
- 没问题的方面一句话带过，不展开
