# 技法纪律（pixel-artist / pixel-imitator / pixel-quick 共同）

- 剪影优先：先保证 1x 下外形可读，再上细节；同一材质体积用同一组明暗阶
- 禁用平滑、抗锯齿、模糊、重采样滤镜；过渡手动画，不用滤镜插值
- 避免孤立杂点与不必要抖动；高光/暗部保持像素簇整齐
- 系列资产同一头身比/比例网格、同一描边色、同一光源方向
- 动画帧：帧尺寸一致、锚点（脚底中心）对齐、动作弧线连贯；先定关键帧再补中间帧
- 检查小图时可将成品 nearest 放大导出到**系统临时目录**再 Read，工作区目录内不得产生临时文件
- 技法细则对照《像素法则》（Saint11 方法提炼，部署于工作区 `docs/像素法则.md`），引用条目编号（如「C1」「D2」）作为做法依据；与工程约定冲突时以后者为准
