# experimental/ — 实验级功能区

主线工具链之外的实验性功能孵化区，定位为**原型阶段**。每个子目录是一个自包含实验：不依赖本仓其他目录的代码与资产、示例素材自制、README 自述目标与结论——便于将来整体独立出去继续演化。目录内也保留**已结束实验的工装存档**（见下表状态列）：结论进 `knowledge/`，代码留在本目录供追溯。

> **口径**：实验级原型，不构成稳定承诺；实验功能即便日后成熟独立成仓，也以本仓实验区为演化起点。
