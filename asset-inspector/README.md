# asset-inspector —— 素材验收台（纯静态单 HTML）

> **定位**：**外部素材进门验收**的交互工具——接收外包 / 购买 / AI 生成的图片、GIF、视频，直观完成尺寸合规检查、颜色提取罗列与像素级取色，为「转换 / 重绘入工程」前的人工把关环节服务。
> 双击即用、离线可用、零依赖（对齐 `scene-previewer` 的单文件 HTML 模式）；跨平台 Windows / macOS，推荐 Chrome / Edge，Safari 16.4+ 可用。

## 使用

双击 `asset-inspector.html`（或用浏览器打开），把素材拖进窗口（或点「打开素材…」多选），左侧队列逐个独立分析；点击队列项切换。

## 功能

- **输入**：PNG / JPEG / WebP / BMP / GIF / MP4 / WebM / MOV，可多选成队列；每个素材独立分析与徽章标注（`宽×高·色数`，超限或 alpha 违规标 ✗）
- **素材信息**：类型、尺寸、帧数（GIF 逐帧解码）、时长、透明像素占比
- **尺寸合规**：
  - 常见档位表（16/32/48/64/96/128 方形起步）逐项 ✓/✗，可增删档位、自定义 WxH（localStorage 持久化，跨会话保留）
  - tile 整除检查（默认 32px，可改）
  - 整数倍缩放适配：1–12 倍内按宽/按高精确命中 720p / 1080p 的倍数
- **颜色提取（当前帧）**：色数 = 不透明唯一 RGB，对照可改上限（默认 16）判读 ✓/✗；alpha 两态检查（只含 0/255，无透明通道格式会注明）；颜色表按占比排序（色块 / HEX / RGB / 数量 / 占比，超 512 色截断显示）
- **合并近似色 → PNG（④，参考图噪声清洗 / 候选稿恢复）**：
  - **合并阈值**（0–100，RGB 欧氏距离）：算法为调色板量化的确定性变体——颜色按占比排序，距离阈值内的归并到**众数代表色**，同一输入恒得同一输出；阈值 > 0 即实时预览处理结果并罗列合并后色表
  - **缩格**（最近邻采样，1/2–1/32）：像素风格大图（如 1024px AI 参考图，逻辑像素 ≈16×16 块）先缩到逻辑网格再合并，直接产出候选稿
  - **alpha 两态化**（默认开，≥128→255 其余→透明，对齐 `pixcli quantize` 口径）
  - **保存为 PNG**（`canvas.toBlob` 无损导出，命名 `<素材>_q<阈值>_d<缩格>.png`）+ 导出合并后调色板 JSON
  - 典型链路：1024px JPEG 像素风参考图（实测 6832–7099 色，JPEG 噪声）→ 1/16 缩格 + 阈值 30 → **15 色 64×64**，产物直接通过 `pixcli check`（exit 0）
  - 边界：合并/缩格属**候选稿恢复手段**（参考图 → 候选素材），正式入库仍走工程流程（pixel-artist/imitator 重绘或用户定案）；对 GIF/视频仅作用于当前帧
- **拾色与导出**：预览区点击像素即拾取该色（透明像素拒绝并提示）；导出调色板 JSON——与 pixel-toolkit `assets/palettes/` 格式一致（`{"name","colors"}`），可直接供 `pixcli quantize` / `check --palette` 消费；复制 HEX 清单
- **视图**：整数倍最近邻缩放（1–32×，大图放不下时降为非整数"仅浏览"模式并标注）、像素网格（z≥4，每 8px 亮线）、悬停读数（坐标 / HEX / alpha）、拖拽平移、`+`/`-` 键缩放
- **逐帧检视**：GIF 解码出帧条，点击缩略图 / `←`→`←`→ 键切帧（帧号与逐帧分析联动）；视频用 ‹帧 / 帧› 步进（1/30 s）与播放统计

## 判读口径与 pixcli 的对应

| 本工具 | pixel-toolkit 对应 |
|---|---|
| 色数 = 不透明唯一 RGB（alpha=0 不计色） | `palette.count_colors` 同口径 |
| 色数 ≤ 上限（默认 16，可改） | `pixcli check --max-colors`（P0/P1 门禁） |
| alpha 两态 ✓/✗ | `pixcli check` 的 alpha 两态 P0 项 |
| 整数倍缩放适配 | 工程约定：渲染端 nearest 采样 + 整数缩放 |

验收通过的素材进入工程后，走 pixel-artist / pixel-imitator 转换重绘（借动作不借皮 / 结构性保色 `pixcli quantize`）。

## 边界与已知限制

- GIF 逐帧解码依赖浏览器 `ImageDecoder`（Chrome / Edge 94+、Safari 16.4+）；不可用时自动退化为首帧分析并在信息区标注
- MOV 能否解码取决于浏览器编解码器（Windows Chrome 对部分 MOV 容器不支持，建议转 MP4 后再验收）
- 照片级大图色数远超 16 属预期（判读会标 ✗ 超限；罗列表按占比截断到 512 行，计数不受影响）
- 本工具管「素材进门验收」；**程序化验证**（生成脚本重跑零差异）由 `pixcli diff` 与 `templates/pixel-art-repro.yml` 承担，规划见 `pixel-toolkit/generation/README.md`
