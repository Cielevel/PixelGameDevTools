# asset-inspector —— 素材处理与验收工具（纯静态单 HTML）

> **定位**：**外部素材进门处理与验收**的交互工具——接收外包 / 购买 / AI 生成的图片、GIF、视频，直观完成尺寸合规检查、颜色提取与近似色合并、描边（自动/笔刷）与像素级取色，为「转换 / 重绘入工程」前的人工把关环节服务。
> 双击即用、离线可用、零依赖（对齐 `scene-previewer` 的单文件 HTML 模式）；跨平台 Windows / macOS，推荐 Chrome / Edge，Safari 16.4+ 可用。

## 使用

双击 `asset-inspector.html`（或用浏览器打开），把素材拖进窗口（或点「打开素材…」多选），左侧队列逐个独立分析；点击队列项切换。

## 功能

面板布局：① 素材信息 → ② 尺寸与结构合规 → **③ 处理与导出（全部操作集中在色表上方）** → ④ 颜色表（处理结果 + 可折叠的原始帧色表）→ ⑤ 拾色。

- **输入**：PNG / JPEG / WebP / BMP / GIF / MP4 / WebM / MOV，可多选成队列；每个素材独立分析与徽章标注（`宽×高·色数`，超限或 alpha 违规标 ✗）
- **素材信息**：类型、尺寸、帧数（GIF 逐帧解码）、时长、透明像素占比
- **尺寸与结构合规**：
  - 常见档位表（16/32/48/64/96/128 方形起步）逐项 ✓/✗，可增删档位、自定义 WxH（localStorage 持久化）
  - tile 整除检查（默认 32px，可改）
  - 整数倍缩放适配：1–12 倍内按宽/按高精确命中 720p / 1080p 的倍数
  - **结构与帧组验收**（2026-09-08 加入，口径对齐 `pixcli check`）：**连通域**（不透明像素 4 连通域数 + 面积序列）与**孤立像素**（4 邻域无相邻不透明像素，记前 8 处）自动作用于**当前显示结果**（处理结果优先、不含笔迹；>400 万像素自动跳过）；「校验帧组」对 GIF 解码帧逐帧算 bbox，检查**帧尺寸一致（P0）/ 脚底 bbox bottom 对齐（P1）/ 水平中心漂移 ≤1px（P1）**
- **③ 处理与导出**（对当前帧生效，操作全部在色表上方；链路顺序固定：缩格 → 去背景 → 合并 → 量化）：
  - **缩格**（1/2–1/32）：像素风格大图先缩到逻辑网格。**alpha 同步缩格**（透明像素不参与色统计；格内不透明占比 ≥1/2 才不透明——2026-09-08 修，此前缩格会把透明背景填回）。**采样方式**三选：**众数**（默认，格内 8 级分桶投票 + ±5 mean-shift，JPEG 噪声在缩格时被统计吸收）/ **中位数**（逐通道）/ **最近邻**（旧行为，取格内左上 1px）
  - **检测网格**：亮度梯度自相关自动检测逻辑像素格距（2–128，含格线相位与置信度），检出后自动填入缩格档位（格距 >32 时动态补 1/N 档）；检测置信度不足时提示手动选档
  - **去背景**（默认开），两种模式：
    - **自动**（对齐 `pixcli standardize --bg auto`）：四角 2×2 均值一致判定背景色，只清除**从画布边界连通**的背景（RGB 距离 ≤16）——被主体包住的同类色（如白底图上的白色高光）保留不挖洞；四角不一致则跳过
    - **绿幕抠图**（键色色度键控，绿幕/蓝幕素材的精准方案）：逐像素按 YCbCr **色度平面距离**判 alpha——只比色品不比明度（主体上明暗不同的近似色不误伤）、不依赖边界连通（**洞内/缝隙背景、渐变打光的绿幕全清**，补足自动模式两大盲区）。「取键色」点画面取色（读原图像素，缩格自动映射）或自动取四角起手；**色度阈值 / 软过渡**（thr~thr+soft 线性 alpha，配合两态化出干净硬边）/ **去溢色**（键色主通道在贴近键色的边缘带内压回另两通道较大值——绿溢回落、其余通道零漂移）三参数实时预览；导出名追加 `_gk<阈值>` 后缀
  - **合并阈值**（0–100）：调色板量化的确定性变体——颜色按占比排序，阈值内归并到**众数代表色**；**色彩空间**可选 RGB 欧氏或 **OKLab 感知色距**（滑杆映射 0–0.2 感知距离）；阈值 > 0 实时预览并罗列合并后色表
  - **量化色数**（不量化/8/16/32/64）：OKLab 加权 k-means（确定性：占比降序种子 + 最远点补齐 + Lloyd 收敛，簇代表取簇内最高频原色）+ 感知色距最近色映射——JPEG 色噪收敛到干净色板，k 为上限（唯一色不足 k 时全保留）
  - **工程调色板载入 + 归板**（2026-09-08 加入）：载入 `assets/palettes/*.json`（`palette.Palette.save` 格式，也接受裸色值数组；色值支持 `#rrggbb` 与 `[r,g,b]`）→ 色块预览 + 「归板」开关（localStorage 持久化）。开启后**替代量化色数**（与 `pixcli --palette` 优先于 `--colors` 同口径）：不透明像素按**精确命中优先 → OKLab 最近色**映射（选色口径 = `palette.quantize`），**alpha 原样保留**（两态化仍归「alpha 两态化」开关）；导出名追加 `_pal<名称>`
  - **alpha 两态化**（默认开，≥128→255 其余→透明）
  - **自动描边**（标准像素画 1px 黑 #000、4 连通）：`附加` = 透明像素邻接不透明 → 外侧补一圈；`转换` = 不透明像素邻接透明/画布外 → 边缘转黑。**非破坏层**：开关只切换显示，不重算不丢失
  - **描边笔刷**：左键拖动涂黑、Alt+拖动擦除、右键拖动平移；笔迹存独立层，开关只切换显示不抹掉（换素材/帧/缩格才作废）
  - **均衡笔刷（残点修复）**（2026-09-09 加入）：绿幕/蓝幕抠图残留像素的逐像素清理。开启后**左键逐像素点击**（不拖刷），把该像素替换为四周 8 邻域不透明色（alpha≥128）的 RGB 均值，再 **OKLab 吸附到图中已有色**（均值不直接落像素，色数不增、不破坏 ≤16 门禁）；**四周全透明的孤立残点点击即清除**（绿幕阴影/褶皱残留）；目标像素透明则不修。修复存**有序记录**（显示坐标系），**调整其他参数后自动按点击顺序重放**（每次在最新处理结果上重算，调参不丢修复）；「撤销」（Ctrl+Z）/「清空修复」随时回退；与描边笔刷互斥；作用于当前显示结果（悬停读数/拾色/结构检查/保存 PNG，文件名追加 `_fx`）；**换素材/切帧/缩格变化作废**；**不参与 sheet / 批量导出**
  - **保存为 PNG**（`canvas.toBlob` 无损，按当前显示画面，命名含 `_q<阈值>_d<缩格><m|med>_c<量化色>_pal<调色板>_ol/_br/_fx` 后缀）+ 导出合并后调色板 JSON + 复制 HEX 清单
  - **批量处理队列**（2026-09-08 加入）：按当前处理参数把队列**每个素材**各处理一遍并导出——`打包 ZIP`（默认；内置 STORE 无压缩 ZIP，同名自动加序号、UTF-8 文件名不乱码）或 `逐个下载`；进度显示在按钮右侧，解码失败的素材单独记录后继续；**笔迹不参与批量导出**
  - **导出 sheet + JSON**（2026-09-08 加入）：当前素材的帧（GIF 全部帧 / 图片 1 帧 / 视频当前帧）逐帧套用当前处理参数 + 自动描边 → `_sheet.png` + `_sheet.json`（Aseprite JSON Hash：`trimmed=false`、`meta.pivot`=脚底水平中心、逐帧 `duration` 100ms 占位、`meta.sourceRoute` 可选 `sampled`/`authored`）；产物可直接用 `pixcli atlas` 校验
  - 典型链路（对齐 `pixcli standardize`）：1024px JPEG 像素风参考图（实测 131–946 色，JPEG 噪声）→ 检测网格（32×32，置信度 0.61）自动 1/32 缩格·众数 → 去背景 → 量化 16 色 → **7 色 32×32 透明底**，产物直接通过 `pixcli check`（exit 0）
- **④ 颜色表**：处理结果色表（启用处理时）+ 原始帧色表（色数/上限判读、alpha 两态检查、按占比排序，超 512 色截断显示）
- **⑤ 拾色**：预览区点击像素拾取该色（描边笔刷点击=涂黑、均衡笔刷点击=修复）；导出拾色 JSON
- **视图**：整数倍最近邻缩放（1–32×，大图放不下时降为非整数"仅浏览"模式并标注）、**像素网格直接叠加在图像上**（含不透明区域），**密度可调**（正整数 = 源像素间距，随缩格按处理后的像素网格计算）、悬停读数（坐标 / HEX / alpha）、拖拽平移（笔刷开启时右键平移）、`+`/`-` 键缩放
- **逐帧检视**：GIF 解码出帧条，点击缩略图 / `←`→`→` 键切帧（帧号与逐帧分析联动）；视频用 ‹帧 / 帧› 步进（1/30 s）与播放统计

## 判读口径与 pixcli 的对应

| 本工具 | pixel-toolkit 对应 |
|---|---|
| 色数 = 不透明唯一 RGB（alpha=0 不计色） | `palette.count_colors` 同口径 |
| 色数 ≤ 上限（默认 16，可改） | `pixcli check --max-colors`（P0/P1 门禁） |
| alpha 两态 ✓/✗ | `pixcli check` 的 alpha 两态 P0 项 |
| 整数倍缩放适配 | 工程约定：渲染端 nearest 采样 + 整数缩放 |
| 连通域数 / 面积序列 | `pixcli check` 的 `域N` 与 `--components-max`（默认信息，设上限才升门禁） |
| 孤立像素（4 邻域无相邻不透明） | `pixcli check` 的 P2 提示（最多记 8 处） |
| 帧尺寸 / 脚底 / 水平中心漂移 | `pixcli check` 帧组检查（P0 尺寸不一致、P1 脚底与中心） |
| 归板（精确命中 → OKLab 最近色） | `pixcli quantize --palette` / `standardize --palette`（alpha 口径见「已知限制」） |
| sheet + JSON 导出 | `pixcli atlas` 一致性门禁（矩形/trim/pivot/tags/`sourceRoute`） |

验收通过的素材进入工程后，走 pixel-artist / pixel-imitator 转换重绘（借动作不借皮 / 结构性保色 `pixcli quantize`）。

## 边界与已知限制

- GIF 逐帧解码依赖浏览器 `ImageDecoder`（Chrome / Edge 94+、Safari 16.4+）；不可用时自动退化为首帧分析并在信息区标注
- MOV 能否解码取决于浏览器编解码器（Windows Chrome 对部分 MOV 容器不支持，建议转 MP4 后再验收）
- 照片级大图色数远超 16 属预期（判读会标 ✗ 超限；罗列表按占比截断到 512 行，计数不受影响）
- 去背景依赖四角同色假设：四角不一致（场景图/照片）自动跳过；被主体包住的背景同色格按连通性保留
- 绿幕抠图按色度距离逐像素判定：与键色**同色品**的主体色（绿衣配绿幕）原理上不可分——调低阈值、对照预览与色表核对；贴近键色的低饱和绿在去溢色高挡位下会被压色（预览可见），挡位以色表零意外为准
- 自动描边 / 合并 / 缩格 / 量化均属**候选稿恢复手段**（参考图 → 候选素材），正式入库仍走工程流程（pixel-artist/imitator 重绘或用户定案）；对 GIF/视频仅作用于当前帧
- **归板与 `pixcli quantize` 的 alpha 口径不同**（2026-09-08）：本工具「归板」保留原 alpha（两态化是独立开关）；`pixcli quantize` 先按 128 两态化、再把 a>0 一律置 255。开「alpha 两态化」后两者逐字节一致（已实测对拍）
- **结构与帧组验收的作用面**：连通域/孤立像素看的是**当前显示结果**（处理结果优先，不含笔迹）；帧组检查只对 **GIF 解码帧**（默认前 60 帧，超出在结果里标注），视频不做逐帧验收——交付前仍以 `pixcli check` 为准
- 批量导出按**当前处理参数**跑整个队列，不含笔迹层；素材较多时用「打包 ZIP」，浏览器对连续下载有数量限制
- **均衡笔刷的修复记录是会话态**（2026-09-09）：不持久化，换素材/切帧/缩格变化即作废；吸附口径 = OKLab 最近**已有色**（处理链输出色集），均值本身不落像素，故修复永不增加色数；sheet 与批量导出不含修复层（同笔迹口径）——修完当前帧直接「保存为 PNG」交付
- **sheet 导出只覆盖当前素材的帧**（GIF 全部帧 / 图片 1 帧 / 视频当前帧），且不含笔迹；跨素材拼 sheet 请用「批量处理队列」导出后自行拼合，或走 `pixcli sheet`
- CLI 侧同构流水线见 `pixcli standardize`（多帧自动共享网格与色板）；算法同源（自相关网格检测、分桶众数、OKLab k-means），实测对照见 `../knowledge/standardization/report-standardization-bench.md`
- 本工具管「素材进门处理与验收」；**程序化验证**（生成脚本重跑零差异）由 `pixcli diff` 与 `templates/pixel-art-repro.yml` 承担，规划见 `pixel-toolkit/generation/README.md`
