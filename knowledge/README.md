## 写入约定

- 新文档进本目录前先想清楚**状态**（现行/已实施/已结论/归档），并更新本索引一行
- 文档引用**本仓**文件用仓库相对路径；引用**部署后**路径（`assets/sprites/`、`tools/pixelart/`、`.zcode/…`、`docs/`）请按 `路径与部署映射.md` 的口径写清
- 同一主题不要留两份并行文档：新方案落地后，把旧方案折成本文附录或标为归档，别让读者猜哪份是当前口径
