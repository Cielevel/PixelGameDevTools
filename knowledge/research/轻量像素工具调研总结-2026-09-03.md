# 轻量可注入像素画工具调研总结（Agent 取向）

> 调研日期：2026-09-03 ｜ AtlasBrain ｜ 主题：轻量工具、无依赖式注入工程、Windows+macOS 跨平台、GitHub 可同步、体积几十 MB 以内，benefit AI Agent 像素作画。全网查询。
> 评估（2026-09-03）：**不采纳，归档备查**——本工具库 `pixel-toolkit` + Pillow 路线即本文推荐的第 4 类形态（Python 轻依赖），清单内工具能力已全覆盖或场景不存在，理由见文末评估记录。

## 结论：四种达标形态

1. **单文件 HTML**（Any Pixel，itch.io）—— 整个工具就是一个 HTML 文件（几百 KB），放仓库随 GitHub 同步，浏览器双击即用，Win/Mac/Linux 全平台，离线可用
2. **WASM 模块**（gametorch/image_to_pixel_art_wasm）—— 几十 KB 级，注入 JS/Web/WebView 工程，跨全平台一致，纯客户端无外呼
3. **单二进制 Rust/C CLI**（atelier / pixelite.rs / csprite）—— 1-3MB 静态二进制，无运行时依赖，Win/macOS/Linux 编译即用
4. **Python 轻依赖包**（proper-pixel-art / retro-diffusion pixel-art-fixer / light-vp pixelart-mcp）—— 包本体 <100KB（无 torch），运行需 Pillow/numpy/opencv（装齐约 50-150MB，适合已有 Python 图像栈的环境）

## 达标清单（体积为 2026-09-03 实测/估算）

| 工具 | 形态 | 体积 | 平台 | Agent 接口 | 亮点 |
|---|---|---|---|---|---|

| atelier（marmikshah） | Rust 单二进制 | ~1-3MB | Win+Mac | **CLI+MCP 25 工具** | offline headless、色板约束、journal 回放、GIF/APNG/spritesheet |

| MiniPixel | Zig 安装器 | 1.4MB | 仅 Win release | 无 | 体积标杆但跨平台打折 |

## 排除
- PixelOE：依赖 torch（GB 级）→ 不符轻量约束
- Pixelorama（Godot 80MB+）、Tilf（Win 52.8MB / Mac 39.9MB，PySide6 打包）、Aseprite（非开源许可+体积）

## Agent 工作流推荐组合（轻量优先）
生成（文本模型/云端）→ **清洗**（proper-pixel-art 或 pixel-art-fixer，AI 脏像素变真像素画）→ **编辑/动画**（atelier 单二进制 MCP，或 pixelart-mcp 本地 Pillow）→ **交付**（spritesheet/GIF/APNG；Web 演示用 WASM 端到端）

## pixel-toolkit 落地评估（2026-09-03，不采纳）

对照本工具库（`pixel-toolkit/` pixcli，Python + Pillow 轻依赖）评估：本工具库路线恰好即本文推荐的第 4 类形态（Python 轻依赖包），清单内 9 个工具能力与 pixcli 高度重叠或场景不存在，**全部不引入**。门禁口径（`pixcli check` exit 0）与 `pixel-toolkit/README.md` 均不变。

| 类别 | 工具 | 不采纳理由 |
|---|---|---|
| 清洗 | proper-pixel-art / pixel-art-fixer | 解决「AI 生成图脏像素→真网格」，本工具库无生成式路线（见《像素画-Agent-调研总结-2026-09-03》不采纳记录）；外部参考导入的结构性保色已由 `pixcli quantize` + alpha 两态化覆盖 |
| 编辑/动画 MCP | atelier / pixelart-mcp | 色板约束、GIF/spritesheet、journal 回放与 pixcli check/sheet/preview + `gen_*.py` 脚本 1:1 重叠；文本生成脚本比 PNG 画布更 git 友好，引入只会形成双工具链、分裂唯一事实源 |
| 微型 GUI | csprite / MiniPixel / Any Pixel | 无 Agent 接口，与派工模式无关 |
| WASM | image_to_pixel_art_wasm | 仅当目标游戏有运行时像素化需求时才有用武之地（按需评估） |
| Agent 范式 | texel-studio | 「逐像素像艺术家一样画」即 pixel-artist + `canvas.py` 现行做法，无增量；且许可非标准 |
