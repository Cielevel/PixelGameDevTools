# 参考图生成约束（生图 AI → 像素转换管线）

用途：角色/资产定案前，先用生图 AI 制作高清参考图，再由转换侧（主代理）按工程像素规范**逐像素手绘转换**（非算法缩放——算法缩放在 32px 档位会糊成泥）。

> 在 Mac 上自动操作即梦出图/下载/读取的机器通路见 `docs/即梦生图-Mac自动化手册.md`；本文档只管 prompt 内容约束。

参考图的定位是**设计规格书**，不是待缩放的原图：转换时大部分细节必然舍弃，图的"信息结构"（视图齐全、色块清晰、特征优先级明确）比细节量更重要。本文档即喂给生图 AI 的约束清单，每次出图照此执行。

## 一次出图的最小信息包

参考图之外，需随图声明（一句话即可）：

1. **目标资产档位**：以工作区 `AGENTS.md` 的尺寸档位为准（各档位尺寸/像素密度全项目单一）；随图注明档位名（如"玩家档""小怪档"）
2. **身份特征优先级**：必须保留的 3–5 条 + 明示可弃细节（见下文示例）
3. **色板**：关键色 hex（主发色/主服装/下装/鞋/肤色/点缀色），或声明"沿用工程既有板"

## 可选信息图（进阶，非必需，按需叠加）

原图单独即可转换（缺信息由转换侧目测判断）；以下信息图各消除一类猜测，独立生效、效果叠加，全部**从同一张基准图派生**（img2img 平涂重绘/剪影化等），禁止让 AI 凭文字分别凭空生成——跨图不一致会引入新歧义。注意它们消除的是"决策歧义"，不能增加像素容量。

| 优先级 | 信息图 | 消除的猜测 | 说明 |
|---|---|---|---|
| 1（单选必配） | **明暗归组版**：同角色直接画成每部件 2–3 阶、光源左上的平涂版 | 色阶分配（渐变哪段归 mid/shadow）——每次转换每个部件的普遍猜测 | 一次 img2img 平涂重绘即可，生成最稳 |
| 2（场景性关键） | **分层图**：按部件拆层（后发/脸/眼/外套/袖/手/裤/靴/持物） | 遮挡关系与部件真实边界 | 有持物、多层服饰的设计上是关键补强；生图 AI 难可靠产出，常需分部件生成或手工拆 |
| 3（可选验证） | **纯剪影图**：单色剪影 | 1x 游戏内可读性凭感觉 | 成本低，用于剪影基准比对 |
| 4（基本不用） | **线稿版**：闭合线稿 | 边界定位 | 价值最低，默认不出 |

引擎式贴图（法线/高度/高光图）**不采用**：那是给实时着色器动态重打光用的逐像素信息，像素转换是固定光源下的一次性手工量化，粒度与范式都不匹配；且 AI 分别生成多张贴图必然互相矛盾。高光意图（眼球玻璃、黄铜可反光）用一行文字声明即可。

## 视图与姿势

- 单个角色，**全身**，站姿（A-pose），双手自然下垂，双脚平踩地面、分开与肩同宽，鞋底轮廓完整可见
- 头顶至脚底完整不裁切，画面居中四周留白
- **视图**：视图需求由工程视角定案决定，以工作区 `AGENTS.md` 为准——俯视四向工程：正面（朝下）**必需**，为定案主视图与承重视图；背面（朝上）**必需**，为朝上向背部造型依据；侧视工程：**90° 纯侧影**必需（单臂贴体、鼻尖轮廓、不露对侧臂眼）。半侧/3/4 参考无对应渲染档位、转换要做减法易失真；3/4 视角不需要。角色左右轮廓不同时（如半脸面具类设计），两侧各出一张或一张图并排，只出一张时优先**特征侧**。动作姿态不靠参考图表现——各朝向与序列帧由动作模板包提供（本包 `asset-packs/`，接入目标工程见 README 复用步骤）
- 不要动态姿势（跑/跳/战斗），不要透视夸张，保持正交感——动作姿态由转换侧按既有模板另配

## 上色与光

- **平涂或硬边赛璐璐上色**，色块边界清晰；禁止软渐变、喷枪、厚涂
- 每个部件明暗控制在 **2–3 阶**（暗/中/亮）内，转换时将按工程色板归组
- **光源统一左上方**（与工程渲染规定一致）；禁止逆光、轮廓光、强环境光
- 面部五官大小以"在游戏内 1x 实体宽度下仍可辨"为度（按工程档位估算画布与身宽）：眼型、发色、耳形优先；其余见下条

## 造型细节边界（1x 像素预算）

- 识别特征优先用**剪影型**（耳形、发型外轮廓、外套/裙摆轮廓、体型），其次**大色块型**（服装主色分区）；花纹型特征（刺绣、图案、小饰品）不可作为唯一识别依据
- 以下细节默认可弃，如需保留必须显式标注：单缕发丝、复杂领型结构、眉毛/腮红/雀斑等面部小元素、织物褶皱与纹理
- **头身比明确声明**（如 Q 版 1:1、1:1.5）；参考与工程档位冲突时以工程档位为准

## 色彩与场景对比

- 高饱和点缀色注意与工程场景底色拉开：角色主色调避免落入与底色相近的低对比区间（具体色彩方向以工程画面约定为准），以免游戏画面内不显眼
- 参考色若超出工程色板，转换侧按「先入板再使用」规则新增入工程对应调色板（`assets/palettes/` 下 JSON）——随图附 hex 可让入板色一次到位，避免目测估色

## 画面洁净（负面清单）

水印、文字、签名、角标（含"AI生成"标）、边框分格线、多角色、背景场景与道具、投影阴影、遮挡身体的持物、软渐变厚涂、逆光/轮廓光、强透视、动态模糊、景深、局部裁切。

## Prompt 模板（复制即用，方括号替换）

> [角色描述，一句话]，Q版全身立绘，正面站姿，双手自然下垂，双脚平踩地面与肩同宽；平涂上色，色块边界清晰，每个部件明暗不超过三阶，光源来自左上方；纯白背景，无阴影，无文字，无水印；全身完整居中，头顶脚底留白。

> 英文备选：full-body chibi character reference, standing A-pose, front view, flat cel shading with hard color edges, max 3 tones per part, light from top-left, plain white background, no shadow, no text, no watermark, head-to-toe fully visible and centered.

多视图版（正+背）：在上述描述中将"正面站姿"替换为"三视图角色设定（正面与背面并排，同一角色同一比例）"（背面即俯视朝上向的背部造型依据，俯视角工程适用；需要侧面时再加）。需要侧面时扩为四视图（正面/背面/左侧/右侧并排），侧面描述写明「正侧面 90° 侧影，单臂贴体，鼻尖轮廓」——不写死易被生图 AI 漂移成 3/4。

## 身份特征清单示例（格式示范，非现行定案）

以某次狐耳少年测试稿为例：

- 必保：直立狐耳（含浅色耳内绒）、橙色碎发剪影、琥珀色大眼（深色上睑）、奶油色短袖衬衫（领口+门襟）、卡其长裤、深棕圆头皮鞋
- 可弃：眉毛、腮红、发丝高光、衣褶

## 转换侧交付约定

- 候选稿**不覆盖**既有 `assets/sprites/` 资产；验收通过后由用户决定是否替换基准，再同步工作区 `AGENTS.md` 与相关基准文档
- 程序化门禁与既有资产一致（`pixcli check` exit 0：尺寸/alpha 两态/色数/调色板）
- 快速测试稿走**极速模式**（`pixel-quick`，单 agent 无 reviewer）：产出统一落 `previews/quick/<资产名>/`（脚本 + 原生 PNG + ×8 预览 + scratch 调色板），该目录不提交、用后即清；新色只进 scratch 板并随交付报告候选色清单。形象定案后才转效率/全量模式正式制作（入板、文档、动画组），极速稿不直接转正

## 极速稿的下游衔接（2026-09-03 两次实测确认）

极速模式出图不是终点，两条下游路均已打通：

**→ 效率/全量 artist 持续优化（主路，默认走这条）**
- 极速稿的规格包 = 原生 PNG（剪影/配色选型）+ 生成脚本（行表几何决策，可直接改参复用）+ scratch 调色板（候选色带用途标注）+ 已知取舍清单；artist 以此为设计规格重绘，比拿原始参考图省一半翻译成本
- 重修按工程档位重绘（如玩家档），不是在快测尺寸上修——跨档位直接缩会糊；稿子的价值在决策不在像素
- 快测若用了偏离档位的尺寸，转正时要么回归工程档位，要么作为基准变更由用户明确确认并同步文档

**→ reviewer 审查（可选，用于重修前拿精确问题清单）**
- 机械通路畅通（reviewer 只读、可审任意 PNG），但派发必须显式附快测规格（尺寸、scratch 板路径、`previews/quick/` 目录、单帧选型稿），并附已有 `pixcli check` 输出走分层审查
- 若裸派不加说明，reviewer 按工作区默认（工程档位/正式板/标准目录与命名）审查，必然判 P0 规格错误——这是审查基准错位，不是稿子的问题
- reviewer 能确认并定位缺口，但不能补细节；细节缺失主因是极速模式的经济约束（≤2 轮、≤16 色、单帧）与像素预算，补细节靠 artist 重修

## 信息图派生 Prompt（基准图定稿后 img2img 使用）

通用前提：以**已选定的基准平涂图**为底图发起图生图，改动强度调低，要求保持角色造型、姿势、比例、服装与底图完全一致；底图含正背两视图时注明"保持两个视图的对应关系"。每张单独生成，不一次输出多图。各图的用途与优先级见上文「可选信息图」。

**明暗归组版（优先级 1，单选必配）**

```
基于这张角色图重新上色：保持造型、姿势、服装、构图与原图完全一致，仅改变上色方式；平涂上色，每个部件（头发、外套、内衬、裤子、靴子、皮肤、配饰）明暗只保留暗、中、亮最多三阶，色块边界清晰锐利；光源统一来自左上方，受光面亮、背光面暗；无渐变、无喷枪、无光晕模糊；纯白背景，无投影，无文字。
```

**分层图（优先级 2，有持物/多层服饰时）**

```
将这张角色图按部件拆分为独立图层：后层头发、身体、脸部、眼睛、前层头发、外套、衣袖、双手、裤子、靴子、手持物；每个部件单独输出一张平涂图，透明背景，部件边缘干净闭合，颜色与原图一致，各部件摆放位置与原图相同；不合并部件，不改变造型。
```

**纯剪影图（优先级 3，可选）**

```
将这张角色图转为纯黑色剪影：只保留完整外轮廓，轮廓内部不区分任何细节、五官与服装分界；边缘干净锐利无毛边；纯白背景，无投影，无文字。
```

**线稿版（优先级 4，默认不出）**

```
将这张角色图转为线稿：深色均匀细线，所有部件边界与服装结构线闭合完整，无上色、无明暗、无排线阴影；造型与姿势与原图保持一致；纯白背景，无文字。
```

## 一键复制：完整 Prompt

替换三处 `[]` 后整段发给生图 AI；若多视图出图质量不稳，拆成正面、背面各出一张。

```
[角色一句话描述]，Q版角色全身设定图，正面与背面两个视图并排，同一角色、同一比例、同一服装；自然站姿，双手垂于体侧，双脚平踩地面与肩同宽，头顶至脚底完整居中不裁切；平涂上色，色块边界清晰锐利，每个部件明暗不超过三阶，光源统一来自左上方，无逆光、无轮廓光；纯白背景，无地面投影，无道具与特效，画面中只有一个角色；配色限定：[主色/下装/鞋/肤色/点缀色的hex]；必须保留的特征：[3-5条剪影级特征]；禁止出现：文字、水印、签名、边框分格、场景背景、软渐变与厚涂、强透视、动态夸张姿势、模糊与景深。
```
